# Mac 万圣节模式

[English](README.md)

把 Mac 的摄像头对着门口。谁走进来，屏幕上就跳出一个骷髅，并把问候读出来：小朋友和宠物看到的是蹦蹦跳跳、挥着棒棒糖的可爱骷髅，大人看到的是扑到眼前的吓人骷髅。

全部在你的 Mac 上运行。负责看画面的是 [tempo9](https://github.com/thinkspread/tempo9) 跑的本地视觉模型，画面不会离开这台机器。

## 安装

```bash
brew install thinkspread/tap/tempo9
brew install thinkspread/tap/halloween
```

## 运行

```bash
halloween
```

第一次运行会下载 Qwen3.5-9B（Q4_K_S）和它的视觉编码器，约 6.4 GB；之后几秒就能启动。浏览器会自动打开 `http://127.0.0.1:1031`，点 **🎃 开始**，允许使用摄像头。

| 摄像头看到… | 它会说… | 骷髅 |
|---|---|---|
| 穿着万圣节服装的小孩 | 不给糖就捣蛋！服装真棒，拿两颗糖吧。 | 可爱 |
| 小孩 | 嗨！万圣节快乐，小朋友。 | 可爱 |
| 穿着奇装异服的大人 | 打扮得不错……可我更吓人。万圣节快乐！ | 吓人 |
| 大人 | 吓到了吧！万圣节快乐！ | 吓人 |
| 狗或猫 | 毛茸茸的客人，没有糖给你哦。 | 可爱 |

每个人只吓一次，走出画面再进来会再吓一次。按开始时画面里的人会被吓第一下。

页面跟着浏览器语言显示中文或英文。开始前右上角的按钮可以切换，点开始后它会藏起来，不会出现在录像里。

不用做任何设置。如果 tempo9 已经带着视觉编码器在跑，`halloween` 直接用它；没在跑就替你启动一个，按 Ctrl-C 时再一起停掉。

## 它怎么决定什么时候看

视觉模型看一帧要一两秒，所以页面不会每一帧都去问它：

1. 每秒把画面缩成 32×18 的小图，和上次量过的画面比较；没变就到此为止。
2. 画面变了，就只交给 tempo9 的视觉编码器（不经过语言模型），得到画面每个区域的向量，看变化最大的那块区域动了多少。
3. 只有这个距离超过阈值时，才问模型「画面里是下面哪一种？」。阈值按摄像头本身的噪声来定。

## 隐私

页面只能连接提供它的那个服务（`Content-Security-Policy: connect-src 'self'`），也就是 `127.0.0.1` 上的 `halloween`。它只把三个请求转给 `127.0.0.1` 上的 tempo9，别的一概不转。骷髅在页面里画，音效是合成的，朗读用的是 Mac 自带的声音。只有第一次运行时，tempo9 下载模型和视觉编码器需要联网。

## 要求

- Apple Silicon 的 Mac，macOS 26（tempo9 的要求）
- tempo9 1.3.0 或更新
- 约 6.4 GB 磁盘空间，用来放模型和视觉编码器

在 24 GB 的 M5 Pro MacBook Pro 上测试过。

## 选项

```
halloween [--port 1031] [--server http://127.0.0.1:11435] [--no-open]
```

- `--port`：页面在哪个端口提供。
- `--server`：指向一个已经在跑的 tempo9，比如你自己用别的模型加 `--tower auto` 启动的那个。
